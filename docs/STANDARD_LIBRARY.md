# Standard Library

Nurture aims to provide common programming functionality through built-in modules.

Core: `write`

File: `read`, `write`, `append`, `exists`, `delete`

Folder: `create`, `exists`, `list`, `delete`

JSON: `read`, `write`, `make`, `parse`

Math: `sqrt`, `sin`, `cos`, `tan`, `floor`, `ceil`, `round`, `abs`, `random`

Crypto: `sha256`

System: `os`, `kernel`, `cpu`, `memory`, `hostname`, `architecture`, `env`

Process: `list`, `info`, `start`, `stop`

Networking: `resolve`, `localip`, `hostname`, `interfaces`, `ping`, `check.port`

Web: `get`, `post`, `put`, `delete`, `request`, `download`, `status`, `headers`, `cookies`
