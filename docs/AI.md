# Nurture AI

AI is intentionally separate from the interpreter.

Potential future features:

- explain selected code
- explain errors
- generate Nurture code from plain language
- context-aware completion
- documentation search
- refactoring
- test generation

Example comment:

```text
# make a window with a login button
```

An optional AI layer could translate the intent into Nurture syntax.

The interpreter remains deterministic and can run without AI or internet access.
